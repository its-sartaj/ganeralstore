## ✨ Features

### 🛍️ Customer Storefront
- **Instant Product Search & Category Filtering**: Browse 500+ items across Staples, Dals, Oils, Dairy, Spices, Tea, Snacks, and Household items.
- **Stock-Aware Shopping Cart**: Enforces real inventory limits, prevents ordering out-of-stock items, and calculates free home delivery milestones.
- **1-Click WhatsApp Ordering**: Automatically formats cart items, savings, and store delivery address into ready-to-send WhatsApp messages.
- **Dual Helpline Support**: Direct calling and WhatsApp support via **`9162288060`** and **`8587079786`**.
- **Interactive Google Maps Navigation**: Built-in shop location navigation link for local customer visits.

### 🧾 Computerized Tax Invoicing & POS Billing
- **Official Print Receipts**: Print-ready GST/Retail memo format with Hindi currency words converter (e.g. *Rupees Four Hundred and Fifty Only*).
- **Dynamic UPI QR Code**: Scan & Pay with Google Pay, PhonePe, Paytm, or BHIM.
- **Counter POS Terminal**: Rapid counter billing for walk-in store customers with live inventory deduction.

### ⚙️ Store Management & Admin Dashboard
- **Admin Access Protection**: Secured with configurable store PIN (Default: `kgs2026`).
- **Low-Stock Alert Badging**: Real-time badge indicators for items running below threshold (`< 2 units`) and out-of-stock items.
- **Product Inventory CRUD**: Add, edit, delete, and restock products with image uploads or online image links.
- **Store Settings Customizer**: Configure store name, tagline, delivery radius, delivery fee, helpline numbers, UPI ID, and Google Maps URL.
- **Invoice Archive**: Search, view, print, and delete past sales records.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# 1. Clone repository
git clone https://github.com/its-sartaj/ganeralstore.git
cd ganeralstore

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
